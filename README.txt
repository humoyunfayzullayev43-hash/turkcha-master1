TURKCHA MASTER — ishga tushirish yo'riqnomasi

1. Papkani ZIP dan chiqaring.
2. Papka ichida terminal oching va quyidagini yozing:
       python -m http.server 8000
   (Python o'rnatilmagan bo'lsa, Python 3 ni python.org dan yuklab oling.)
3. Brauzerda oching: http://localhost:8000

Telefonda: kompyuter va telefon bir Wi-Fi da bo'lsa, kompyuterning IP manzili
bilan oching (masalan http://192.168.1.10:8000). Chrome menyusidan
"Ekranga qo'shish" / "Install app" ni tanlang.

MUHIM: Ma'lumotlar brauzerda (IndexedDB) saqlanadi. Muhim lug'atlaringizni
muntazam ravishda "Zaxira" bo'limidan JSON qilib yuklab oling.
